# No Pants Anime Software — Master Plan v1.2
Approved 2026-11-06. Mission: phone-first, professional-looking original anime films, beginning with a five-second lavender heroine shot. $0 paid APIs/compute unless explicitly approved; do not require the user's desktop.

## Binding execution rules
1. ONE MISSION: declare deliverable, quality impact, inputs, evidence, budget and exit before work. No unapproved scope expansion.
2. ANIME-FIRST: procedural cartoons are permitted only as labeled unit-test fixtures; never substitute for artistic deliverables.
3. TWO-ATTEMPT BREAKER: maximum two materially distinct attempts per blocker; parameter retries do not reset count. Stop, document, escalate.
4. EVIDENCE FIRST: a successful CI job, frame count or MP4 existence does not prove artistic quality. Missing output/reference/inspection = UNVERIFIED.
5. REUSE FIRST: inspect working components before new code. Preserve verified Blender/Synfig, continuous_engine, MediaPipe, audio and assembly workflows.
6. BOUNDED EFFORT: declare per-session limits before tools; default one mission, one small prerequisite, two attempts/blocker, no unrelated builds. Stop when exhausted.
7. QUALITY IMPACT: work must directly improve accepted anime or remove a verified critical-path blocker. Park everything else.
8. NO GUARDIAN RABBIT HOLE: plain Markdown/JSON only; no dashboard, database, agent framework, or new renderer for Mission 01.
9. PHONE FIRST: iPhone -> remote generative video -> review -> existing GitHub assembly -> MP4.
10. REPORT SEPARATELY: infrastructure readiness, actual generative video execution, and artistically accepted anime; no invented overall percent.

## Current evidence
Continuous engine: prior reported successful 120-frame/24fps 5-second CPU test, visually defective, using procedural keyframes. Blender primitive; Synfig static. Wan local launcher only static-tested; no model video. Candidate lavender heroine generated in chat but not approved or confirmed in repository.

## Exit criteria for first anime shot
Approved original reference; genuinely generated playable MP4; stable face/hair/outfit; believable blink, smile, five-finger wave; no obvious ghosting/flicker or catastrophic anatomy; human visual approval. Technical and artistic acceptance are separate.

## Session protocol
Read this charter, quality_guardian/QUALITY_GATES.json and quality_guardian/SESSION_HANDOFF.md before acting. Declare mission and attempt budget; log results; stop on breaker; update handoff and report next exact prompt. These are project instructions, not an autonomous enforcement mechanism.
