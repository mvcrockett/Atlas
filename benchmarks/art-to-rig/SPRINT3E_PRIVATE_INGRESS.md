# Operation NoPants Sprint 3E — private artwork ingress

**Status: pipeline staged, unapproved real-art native Stretchy rendering not yet demonstrated.**

The repository is public. User-supplied imagery must remain outside git history, commit comments, plaintext runner artifacts and public logs.

## Private input ZIP
The locally prepared fixture consists of manifest.json, detailed head and hair textures, torso underpaint, minimal closed-eye and mouth redraw overlays, the original comparison source and selected Sprint 3D reference images. It is labeled `UNAPPROVED_TECHNICAL_FIXTURE` and `approval: false`.

## Required Actions configuration
Repository maintainers must configure these three settings under GitHub Actions encrypted repository secrets, without disclosing their values in conversation or issue comments:

- `NOPANTS_ART_BUNDLE_URL`: an expiring HTTPS direct-download link to the privately hosted ZIP.
- `NOPANTS_ART_BUNDLE_SHA256`: SHA-256 digest of exactly that ZIP.
- `NOPANTS_EVIDENCE_KEY_HEX`: 32 randomly generated bytes encoded as 64 hexadecimal characters, retained independently for decrypting the finished artifact.

The runner validates the archive, mounts the textures only in ephemeral workspace storage and uses pinned upstream Stretchy ScenePass and animation engine for 72 native frames at 24fps.

Video, frame samples, metrics and telemetry are AES-256-GCM encrypted before output upload. Only ciphertext and generic status text can become Actions artifacts. Use `sprint3e_decrypt_evidence.py` on a trusted machine with the independently retained key to view actual results.

## Triggers and blockers
The workflow deliberately avoids a default-branch write or any pull-request trigger. Its protected experimental-branch push trigger permits fail-closed preflight; GitHub's manual workflow-dispatch UI generally requires the workflow file on the default branch. Without configured inputs the job must stop without downloading imagery. Re-run the preflight after provisioning the assets and settings.

Do not claim successful anime-native rendering until the GitHub run passes, encrypted evidence is retrieved and independently decrypted and inspected. The Sprint 3D reference is 280x470 while native output is 480x480, so unregistered per-pixel comparisons are misleading.
