# Focused international reuse screen — 2026-11-06

This is a source/documentation screen, not a new engine tournament. Country labels below identify documented institutions or project histories, not inferred maintainer nationality. No model weights downloaded and no new inference service called. Keep Stretchy on the critical path because its actual private output now exists.
