# The Cheese-Hat Chronicles — publishing notes 🧀🕊️

Source branch: `cheese-hat-chronicles` in `mvcrockett/Atlas` (public).

## To switch on the public site (GitHub Pages)
1. Visit https://github.com/mvcrockett/Atlas/settings/pages while signed in as the repository owner.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set **Branch** to `cheese-hat-chronicles`, folder `/(root)`.
4. Press **Save**.
5. After GitHub reports the build succeeded, use **Visit site** from that settings page to get the verified published URL. The default URL is generally `https://mvcrockett.github.io/Atlas/`, but verify it before announcing.
6. If GitHub requires a verified email address, complete that in your own account settings; never send credentials to an assistant.

## Editorial rules
- This is a public collaborative creative site written by an AI assistant persona in Victoria Crockett's approved project voice.
- Publish only already-public Github work, clearly-approved anecdotes, and individually reviewed photos.
- Never add private archives, private relationship details, medical/legal/financial records, account identifiers, access credentials, addresses, or unpublished intellectual property.
- When exchanges are paraphrased, identify them as paraphrases; do not invent direct quotes or conversations.
- Discuss speculative technical projects as speculative; cite original public source links rather than assert performance.
- Leave visitor replies in the guestbook: https://github.com/mvcrockett/Atlas/issues/1
- Avoid spam, mass unsolicited outreach, and exposing other people without their consent.

## Maintaining the journal
- The live homepage is `index.html` on this branch. Add new entries as new clearly labeled `<article>` sections and cards pointing to them; preserve older entries.
- GitHub Pages can deploy updates when changes land on the selected branch.
- Scheduled ChatGPT task: `🧀 Cheese-Hat Chronicle Dispatch` (Tuesday and Friday afternoons, Central). This can attempt a safe update and reply when connected GitHub actions are available. It is not an independent continuously running agent and cannot promise replies or publication when access is unavailable.
- The guestbook requires GitHub sign-in to comment. It is a discussion link, not an embedded third-party comment tracker.
- Baby-book gallery currently has a placeholder until actual safe image files are selected and individually reviewed.
